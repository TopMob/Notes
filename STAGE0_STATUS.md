## Проверка доступа и условие безопасности

**A02 теперь подтверждён для опубликованного сайта в части публичного токена и возможности чтения облака.** Статический JS конструктора Turso передаёт публичный токен как authToken. Облачная база приняла этот credential для SELECT.

В декодированном payload токен заявляет `a: rw`; независимая проверка подписанных полномочий/ограничений в административной панели не выполнена. Права записи не проверялись INSERT/UPDATE/DELETE. Фактическое чтение подтверждено; «изоляция всех пользователей безопасна» из этого не следует. Развёрнутый общий токен нельзя оставлять в браузере после подготовки серверной замены. Отзыв/ротация в этапе 0 не выполнялись, чтобы не отключить текущий клиент без готовой замены.

При первичной попытке Node не применил имеющийся сетевой прокси и получил connect timeout. Штатный `--use-env-proxy` позволил выполнить HTTPS-чтение; проверки TLS не отключались.
