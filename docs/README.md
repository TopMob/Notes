## Установка синхронизации Supabase

Готовый SQL-пакет: [`../scripts/supabase-sync-v1.sql`](../scripts/supabase-sync-v1.sql). Открой его и выполни в SQL Editor нужного проекта Supabase. Пакет добавляет атомарные RPC для синхронизации, таблицу манифестов изображений и закрытый bucket `notes-assets`.

Миграция сохраняет строки заметок, но заменяет RLS-политики четырёх таблиц заметок и отзывает у `authenticated`/`anon` прямые права записи. После неё изменения должны идти через RPC. Если эти таблицы или Storage используются другими функциями проекта, сначала проверь политики и типы `pages.camera`/`pages.background`; не запускай пакет вслепую на общем Supabase-проекте. Скрипт останавливается при несовместимых типах столбцов.

После выполнения проверь вход через Clerk и синхронизацию одной тестовой страницы с изображением. Пока SQL не установлен, приложение продолжает локально сохранять заметки, а для облака можно использовать Turso.
