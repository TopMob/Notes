# Notes

Веб-приложение заметок с бесконечным холстом в духе OneNote.

## Возможности

- заметки и страницы на бесконечном холсте;
- рисование и работа с содержимым страницы;
- локальная работа с данными;
- синхронизация через Supabase (настраивается отдельно).

Проект находится в активной разработке. Некоторые функции и интерфейсы могут меняться.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки:

```bash
npm run build
npm run preview
```

## Проверки

```bash
npm test
```

Технические аудиты, история исправлений и инструкция по настройке синхронизации находятся в [`docs/`](docs/README.md).

## Стек

Vite, TypeScript, React, Supabase, IndexedDB.
